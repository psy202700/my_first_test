# 하위 프로젝트: 인수인계 인터뷰 어시스턴트

루트의 메뉴 추천 앱과는 별개인 프로젝트다. 이 폴더 안의 작업에는 이 문서를 우선 적용한다.

## 기술 스택
- 서버: Node.js 20+, `node:http` (프레임워크 없음), 의존성은 `@anthropic-ai/sdk` 하나만 둔다
- 화면: `public/`의 바닐라 HTML/CSS/JS, 빌드 도구 없음
- 저장: `data/sessions/<id>.json` (git에 올리지 않음)

## 규칙
- 인터뷰 진행 원칙(8개 대분류, 5개 슬롯, 업로드 요청 조건과 횟수 제한, 확인 루프)은 `lib/prompts.js`에 있다.
  숫자로 셀 수 있는 제약(업로드 요청 횟수 등)은 프롬프트에만 맡기지 말고 `lib/state.js`에서 센다.
- 대화 기록(`apiMessages`)에는 추가만 한다. 이전 메시지를 고치거나 thinking 블록을 지우면 안 된다.
- 문서 생성은 추측 금지, 근거가 없으면 "확인 필요"로 표시한다.

## 확인 방법
- `npm test` (API 호출 없이 가짜 LLM으로 전체 흐름을 검증)
- `ANTHROPIC_API_KEY` 설정 후 `npm start` → http://127.0.0.1:8787
